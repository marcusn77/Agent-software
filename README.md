# Agent Software

This repo contains a small starter backend for a voice AI / lead calling app.

## Included
- Fastify server entrypoint: `server(1).js`
- Database stub: `db.js`
- Route mount helper: `mount.js`
- Example module structure for campaign queue, CRM webhook, and call session lifecycle

## Quick start

1. Install dependencies
   ```bash
   npm install
   ```
2. Copy the environment file and adjust values
   ```bash
   cp .env.example .env
   ```
3. Start the app
   ```bash
   npm start
   ```

## Notes
This is a working starter skeleton. Replace the stubbed database, CRM webhook, and queue code with your production implementations.
